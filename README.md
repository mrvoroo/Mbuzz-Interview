# ملف انترفيو MBUZZ

صفحة تفاعلية (ملف واحد `index.html` بدون أي تثبيت) للتحضير لانترفيو شركة MBUZZ السعودية (mbuzz.com). مبنية على بحث بتاريخ 17 نوفمبر 2026، وكل معلومة عليها درجة ثقة ومصدر.

> ملف تحضير شخصي، غير تابع لشركة MBUZZ.

## التشغيل

افتح `index.html` في أي متصفح. الصفحة بتحمّل خطوط Google Fonts، فلازم إنترنت علشان الشكل يظهر مظبوط.

## الاستخدام

- **البحث:** اكتب أي كلمة (Magna، H100، Phison، 2007) وهتشوف كل المعلومات المرتبطة في كل الأقسام.
- **فلتر الثقة:** مؤكد / بحذر / لا تذكره / رأيي. قبل الانترفيو شغّل «مؤكد» بس.
- **حدود الدقة:** راجع التاب ده الأخير قبل الدخول. فيه اللي ما تقولهوش واللي ملقيتش عنه معلومة.
- **الأسئلة والردود:** كل سؤال فيه رد مقترح ونقاط ثابتة تحفظها. عدّل الردود بكلامك.
- **قايمة التحقق:** بتتحفظ في متصفحك.

## التحديث

كل المحتوى جوه `index.html` في كائنات JavaScript (`P` و`QA` و`PRJ` و`S` للمصادر). عدّل النص هناك. لو معلومة اتأكدت، غيّر درجتها من `mid` إلى `ok`.

## النشر

لو عايز تفتحها من الموبايل برابط: فعّل GitHub Pages من إعدادات الريبو (Settings ثم Pages ثم Deploy from a branch ثم `main`). انتبه إن الصفحة هتبقى علنية لو الريبو public.
